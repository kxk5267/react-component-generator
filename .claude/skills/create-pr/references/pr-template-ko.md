# PR 템플릿 (한국어)

한국어 프로젝트에서 사용한다. 섹션 구조는 유지하고 내용만 채운다.

```markdown
## 요약
<!-- 이 PR이 무엇을 하는지 1~3문장 -->

## 변경 배경
<!-- 왜 필요한가? 해결하려는 문제나 요구사항. 관련 이슈: Closes #N -->

## 주요 변경 사항
<!-- 커밋 나열이 아니라 의미 단위로 -->
-
-

## 테스트
<!-- 실제로 실행한 것만 체크한다. 실행하지 않았다면 사유를 적는다 -->
- [ ] 단위 테스트
- [ ] 린트 / 타입체크 / 빌드
- [ ] 수동 확인 (확인한 시나리오:)

## 리뷰 포인트
<!-- 중점적으로 봐주었으면 하는 부분, 트레이드오프, 알려진 제약. 없으면 "해당 없음" -->

## 스크린샷
<!-- UI 변경 시 전/후. 없으면 "해당 없음" -->

## 체크리스트
- [ ] 변경 범위가 하나의 목적에 집중되어 있다
- [ ] 민감 정보(키, 토큰)가 포함되지 않았다
- [ ] 필요한 문서를 갱신했다
```
