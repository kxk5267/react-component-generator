# PR Template (English)

Use for English-language projects, especially open source projects that accept outside contributors. Keep the section structure and fill in the content only.

```markdown
## Summary
<!-- What does this PR do? 1-3 sentences -->

## Motivation
<!-- Why is this needed? The problem or requirement. Related issue: Closes #N -->

## Changes
<!-- Group by meaning, don't just list commits -->
-
-

## Testing
<!-- Check only what you actually ran. If something was not run, say why -->
- [ ] Unit tests
- [ ] Lint / type check / build
- [ ] Manual verification (scenarios:)

## Notes for Reviewers
<!-- Areas needing careful review, trade-offs, known limitations. "N/A" if none -->

## Screenshots
<!-- Before/after for UI changes. "N/A" if none -->

## Checklist
- [ ] The change is focused on a single purpose
- [ ] No secrets or credentials are included
- [ ] Documentation is updated where needed
```
